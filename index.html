EdgeMambaFormer: Edge-Guided Cross-Scale Mamba Transformer with Wavelet-Based Boundary Attention for Colonoscopy Polyp Segmentation

A tri-hybrid CNN–Mamba–Transformer architecture built on a PVT v2-B2 encoder, combining a parameter-free Wavelet Edge Attention Gate (WaveletEAG), a bidirectional Cross-Scale Mamba Module (CSMM) for linear-complexity global context, and a dual-branch (local window + global) Transformer decoder — achieving state-of-the-art results on 3 of 4 independently trained colonoscopy polyp benchmarks.

Key Contributions

  • Introduced WaveletEAG, using a 2-D Haar Discrete Wavelet Transform to extract multi-directional boundary signals (horizontal, vertical, diagonal) without any learned convolutional edge detector, fused with semantic context via a learnable sigmoid gate
  • Designed CSMM, which jointly tokenises multi-scale encoder features into a single sequence and applies a bidirectional selective-scan SSM (S6) for cross-scale global dependency modelling at linear complexity
  • Achieved 0.935 mDice / 0.884 mIoU on Kvasir-SEG, 0.941/0.892 on CVC-ClinicDB, and 0.889/0.812 on CVC-ColonDB (+8.1 pp mDice over Polyp-PVT), with a compact 25.4M-parameter footprint
  • Validated each module via ablation; manuscript prepared for submission to Computers in Biology and Medicine

MSHFNet: Multi-Scale Hybrid Fusion Network for Precise Multi-Organ Abdominal CT Segmentation

A novel multi-scale hybrid fusion architecture that combines convolutional and transformer-based feature extraction pathways to achieve precise segmentation of multiple abdominal organs in CT scans. The network leverages multi-scale feature fusion to capture both fine-grained local structures and long-range anatomical context simultaneously.

Key Objectives

  • Design a multi-scale hybrid encoder fusing CNN local features with Transformer global context for abdominal organ boundaries
  • Develop a cross-scale feature fusion module to integrate representations across spatial resolutions
  • Achieve robust simultaneous segmentation of multiple organs including liver, spleen, kidneys, and pancreas
  • Evaluate on public CT benchmarks (BTCV, CHAOS) with Dice and HD95 metrics

Diffusion Model Integration in Semi-Supervised Learning for Image Segmentation

Exploring the integration of diffusion probabilistic models within a semi-supervised learning framework to improve segmentation performance under limited annotation regimes. The approach leverages the generative power of diffusion models to learn rich, transferable visual representations without requiring dense pixel-level labels during pre-training.

Key Objectives

  • Integrate denoising diffusion probabilistic models (DDPM) as a pretext task for semi-supervised feature learning
  • Design a unified pre-training strategy that conditions diffusion on semantic structure for downstream segmentation
  • Evaluate representation quality under low-label regimes on medical and natural image benchmarks
  • Reduce dependency on large annotated datasets while maintaining competitive segmentation accuracy
